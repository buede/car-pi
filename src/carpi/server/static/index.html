Before you start

This tool reads. It cannot change anything in a car. The services that could write, and the one that clears fault codes, are not implemented at all.

Ask the owner before plugging into a car that is not yours. Reads are non-invasive, but it is still someone else's property.

car-pi is pre-alpha, and its vehicle database is nearly empty on purpose. A question the car does not answer is reported as not assessed, never as a pass. Absence of a finding is not evidence of a sound car.

Enter what the seller claims, in kilometres, and the report will cross-check it against what the engine controller actually holds. Mileage tampering usually only rewrites the instrument cluster.

Ignition ON, not accessory — many modules stay asleep in accessory mode.

What will be checked

Every check car-pi knows about, worst first. A check whose data this car does not report is reported as not assessed rather than passed.

Scanning

    Some faults only appear in motion. Fuel trims that look fine at idle can be badly off under load, and a coolant temperature that never climbs is invisible in a snapshot. Have somebody else drive.
